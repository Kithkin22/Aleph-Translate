# Design reference files

Drop screen recordings, screenshots, or mockups here so agents can match the intended UX.

## How to share a reference video

1. Copy your file into this folder, e.g. `docs/reference/goodnotes-zoom-example.mp4`
2. Commit and push, or attach the file directly in Cursor chat
3. Mention the filename in your message

Local Mac paths (e.g. `/Users/you/Downloads/...`) are **not** visible to cloud agents.

## Current target

GoodNotes-style translate workflow:

- PDF visible above
- Zoom writing window at bottom (~35% height)
- Blue focus rectangle on PDF synced with zoom window
- **Hebrew:** zoom window advances **right to left**
- Scribble back-and-forth to erase ink
